### Why a Portfolio?

A portfolio with GitHub Pages is **free, easy to set up, and version-controlled**. It allows showcasing projects, coding skills, and technical writing with a professional online presence. Since it's hosted on GitHub, it integrates well with repositories. Besides, it supports custom domains for a personalized touch.
